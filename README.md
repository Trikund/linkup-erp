# LinkUp ERP 🚀

**One Platform. Every Organization.**

LinkUp is a modern, comprehensive, and scalable SaaS ERP platform built with **React, TypeScript, Tailwind CSS, and Vite**. It is designed to unify operations across different types of organizations, providing dedicated portals for Schools, Colleges, and Corporate environments.

![LinkUp Banner](https://images.unsplash.com/photo-1541339907198-e08756dedf3f?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Key Features

### 1. Unified Architecture
- A single frontend platform serving multiple organization types (School, College, Corporate).
- Intelligent routing and dynamic layout rendering based on the selected organization and user role.

### 2. School Management (Phase 2 & Redesign)
- **Student Portal:** Beautiful, ultra-wide glassmorphic dashboard featuring attendance tracking, assignment submissions, daily schedules, and rich CSS-based performance charts.
- **Teacher Portal:** Class management, submission evaluations, grading, and dynamic timetable views.
- **Parent Portal:** Multi-child support with toggle functionality, detailed progress tracking, fee management, and teacher remarks.
- **Admin Portal:** High-level statistical view (Donut/Bar charts) for enrollments, fee collections, and staff management.

### 3. College/University ERP (Phase 3)
- Fully distinct navigation and vocabulary (e.g., "Faculty" instead of "Teacher", "Semesters" instead of "Terms").
- Dedicated dashboards for College Students, Faculty, Parents, and College Admins.

### 4. Corporate & Workforce Management (Phase 4)
- **Employee Portal:** Task tracking, leave applications, and KPI monitoring.
- **Manager Portal:** Team analytics, project management, and attendance approvals.
- **HR Portal:** Recruitment pipelines, onboarding, and payroll overviews.
- **Corporate Admin:** Organization-wide analytics, department management, and policy enforcement.

### 5. AI Assistant & Chatbot
- Integrated floating **LinkUp Assistant**.
- Context-aware routing suggestions, FAQ handling, and simulated conversational AI capabilities.

## 💻 Tech Stack

- **Framework:** React 18
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (Modern Glassmorphism, Gradients, and Soft Shadows)
- **Icons:** Lucide React
- **Routing:** React Router v6
- **Animations:** Framer Motion

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
   \`\`\`bash
   git clone https://github.com/Trikund/linkup-erp.git
   cd linkup-erp
   \`\`\`

2. **Install dependencies**
   \`\`\`bash
   npm install
   \`\`\`

3. **Start the development server**
   \`\`\`bash
   npm run dev
   \`\`\`
   The application will be available at \`http://localhost:5173\`.

### Production Build
To create a production-ready build:
\`\`\`bash
npm run build
\`\`\`
This compiles the TypeScript files and bundles the React application into the \`dist\` directory.

## 🎨 Design Philosophy

LinkUp follows a premium SaaS design language:
- **Clean & Professional:** Minimalist layouts utilizing extensive whitespace.
- **Glassmorphism:** Frosted glass effects for sidebars and floating elements.
- **Dynamic Theming:** Color palettes adapt to the organization type (e.g., Blue/Cyan for Schools, Deep Navy for Corporate).
- **Responsive:** Fully optimized for both mobile and large desktop displays.
